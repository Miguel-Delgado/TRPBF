# Тема работы: Система организации турниров
## Назначение
Приложение предназначено для упрощения процесса создания и управления турнирными сетками. На начальном этапе реализован сценарий формирования пар участников для первого тура соревнований.

## Целевая аудитория
- Организаторы любительских и профессиональных турниров (спортивных, киберспортивных, интеллектуальных).
- Участники, желающие быстро получить информацию о своих соперниках.
- Администраторы мероприятий, нуждающиеся в автоматизации жеребьёвки.

## Описание предметной области
Турнир — это соревнование, в котором участники состязаются друг с другом по определённым правилам. Организация турнира включает:
- регистрацию участников;
- формирование пар (жеребьёвку);
- проведение матчей;
- учёт результатов;
- определение победителя.

Данное приложение фокусируется на первых двух этапах: вводе списка участников и случайном распределении их по парам для первого раунда.

## Основные сущности
- **Турнир** — содержит название, список участников, список пар.
- **Участник** — имеет имя (строка).
- **Пара** — два участника, встречающиеся в матче.

## Основные функции
1. Создание турнира (ввод названия).
2. Добавление участников (ввод имён).
3. Проверка чётности количества участников (при нечётном количестве добавляется виртуальный участник "bye").
4. Случайная жеребьёвка (перемешивание списка и разбивка на пары).
5. Вывод сформированных пар на экран.

## План развития проекта
1. **Расширение функциональности**:
   - реализация нескольких туров (плей-офф);
   - ввод и учёт результатов матчей;
   - определение победителя турнира.
2. **Улучшение интерфейса**:
   - переход на веб-интерфейс или GUI (Tkinter);
   - поддержка импорта/экспорта данных (CSV, JSON).
3. **Работа с данными**:
   - сохранение турниров в файл;
   - загрузка ранее созданных турниров.
4. **Дополнительные возможности**:
   - ручная корректировка пар;
   - учёт рейтинга участников (посев).
5. **Тестирование и документация**:
   - покрытие модульными тестами;
   - создание подробной пользовательской документации.
