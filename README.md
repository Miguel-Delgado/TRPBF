## Назначение

Приложение предназначено для автоматизации начального этапа организации турниров – создания турнира, регистрации участников и формирования пар для первого тура (жеребьёвка). Проект разрабатывается как индивидуальный и в перспективе будет расширен до веб-приложения на Django.

## Целевая аудитория

- Организаторы любительских и профессиональных соревнований (спорт, киберспорт, интеллектуальные игры).
- Администраторы мероприятий, желающие быстро провести жеребьёвку.
- Участники, которые хотят заранее узнать своих соперников.

## Описание предметной области

Турнир – это соревнование, в котором участники встречаются друг с другом по определённым правилам. Ключевые этапы:

1. Регистрация участников.
2. Жеребьёвка (формирование пар).
3. Проведение матчей.
4. Фиксация результатов.
5. Определение победителя.

На данном этапе реализованы первые два этапа. При нечётном количестве участников автоматически добавляется виртуальный игрок "bye", который даёт техническую победу сопернику в первом туре.

## Основные сущности

- **Турнир** – имеет название, список участников, список пар.
- **Участник** – строка с именем.
- **Пара** – кортеж из двух имён (участников).

## Основные функции (реализованы)

| Функция | Описание |
|---------|----------|
| `create_tournament()` | Запрашивает название турнира, возвращает строку. |
| `add_participants()` | Запрашивает количество и имена участников, возвращает список. |
| `ensure_even_number()` | Проверяет чётность количества участников, при необходимости добавляет "bye". |
| `draw_pairs()` | Перемешивает список и разбивает на пары. |
| `display_pairs()` | Выводит пары на экран с учётом автоматического прохода при "bye". |

Все функции являются чистыми (принимают данные и возвращают результат), что упрощает тестирование и интеграцию с другими системами.

## Текущая реализация

- Язык: Python 3.
- Используемые конструкции: переменные, ввод/вывод, преобразование типов, ветвления, циклы, импорт модуля `random`.
- Данные хранятся в списках и кортежах (встроенные структуры).
- Код разбит на логические функции – каждая решает одну задачу.
- Сценарий работы: пользователь вводит название турнира, затем список участников, программа автоматически выполняет жеребьёвку и показывает пары.
