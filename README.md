## Назначение

Приложение предназначено для автоматизации начального этапа организации турниров – создания турнира, регистрации участников и формирования пар для первого тура (жеребьёвка). Проект разрабатывается как индивидуальный и в перспективе будет расширен до веб-приложения на Django.

## Целевая аудитория

- Организаторы любительских и профессиональных соревнований (спорт, киберспорт, интеллектуальные игры).
- Администраторы мероприятий, желающие быстро провести жеребьёвку.
- Участники, которые хотят заранее узнать своих соперников.

## Описание предметной области

Турнир – это соревнование, в котором участники встречаются друг с другом по определённым правилам. Ключевые этапы:

1. Регистрация участников.
2. Жеребьёвка (формирование пар).
3. Проведение матчей.
4. Фиксация результатов.
5. Определение победителя.

На данном этапе реализованы первые два этапа, а также сохранение и загрузка данных. При нечётном количестве участников автоматически добавляется виртуальный игрок "None_name" (bye), который даёт техническую победу сопернику в первом туре.

## Основные сущности

- **Турнир** – словарь с ключами `name`, `participants`, `pairs`.
- **Участник** – словарь вида `{"id": 1, "name": "Иван"}`.
- **Пара** – словарь вида `{"player1": "Иван", "player2": "Петр"}`.

## Формат хранения данных

Данные турнира хранятся в файле `data/tournament.json` в кодировке UTF-8:

```json
{
    "name": "Кубок города",
    "participants": [
        {"id": 1, "name": "Иван"},
        {"id": 2, "name": "Петр"}
    ],
    "pairs": [
        {"player1": "Иван", "player2": "Петр"}
    ]
}
```

При загрузке обработываются исключения: `FileNotFoundError` (файла нет — создаётся новый турнир), `json.JSONDecodeError` (данные повреждены — создаётся новый турнир), проверяется, что данные являются словарём, отсутствующие ключи дополняются значениями по умолчанию.

## Обработка исключений

- `utils.input_int()` – перехват `ValueError` при вводе нецелого числа или числа ≤ 0, повторный запрос.
- `storage.save_tournament()` – перехват `OSError` при записи файла.
- `storage.load_tournament()` – перехват `FileNotFoundError` и `json.JSONDecodeError`.

## Текущая реализация

- Язык: Python 3 (типизация через аннотации).
- Код разбит на модули: логика (`tournament`), хранение (`storage`), ввод/вывод (`main`, `utils`).
- Данные представлены словарями и списками словарей — удобно для JSON и будущей базы данных Django.
- Данные сохраняются в JSON и загружаются при старте приложения (модуль `json`, контекстный менеджер `with`).
- Консольный интерфейс: меню с пунктами создания турнира, добавления участников, жеребьёвки, просмотра, сохранения и загрузки.
- Автотесты на `pytest` покрывают логику турнира и работу хранилища.

## Инструкция по запуску

1. Установите зависимости (необязательно для работы приложения, но нужно для тестов и проверки кода):
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите из корня проекта:
   ```bash
   python main.py
   ```
3. Работайте с меню: создайте турнир (1), добавьте участников (2), проведите жеребьёвку (4), сохраните (6). При следующем запуске турнир загрузится автоматически.

## Запуск тестов

Из командной строки **в корне проекта** (важно: команда `py`, а не `python` — на Windows `python` может быть заглушкой Microsoft Store):

```bash
py -m pytest tests -v
```

Не запускайте файл `tests/test_tournament.py` напрямую (кнопкой Run или как скрипт) — его выполняет pytest, иначе будет ошибка `ModuleNotFoundError`.
